# ☎️ もしもしAI — 受話器で話すだけの、高齢者向けデジタル端末

**「受話器を取って話すだけで、若い人と同じ便利さを。そして特殊詐欺から守る。」**

今のスマホの代わりになる、高齢者向けのデジタル端末の構想です。
タブレットに**受話器をつないだだけ**のシンプルな形で、AIエージェントが本人の代わりにネットショッピングや予約・手続きを行います。本人は画面で内容を確かめて **「OK」を押す／少し直す** だけ。

> 公益性の高いアイデアだと考え、誰でも使い・作り・改良できるようにここで公開します（公開日：2026年11月3日）。

---

## なぜ作るのか
- ネットショッピング、ネットスーパー、オンライン予約、キャッシュレス……。若い人が当たり前に使っている便利さを、高齢者は**操作の難しさ**のせいで使えていません
- 一方で、高齢者を狙う**特殊詐欺**（オレオレ詐欺、還付金詐欺、警察官をかたる詐欺など）の被害は今も深刻です
- 高齢者が一番慣れている動作は **「電話をかけること」**。それなら電話の形のままAIにつなげばいい、という発想です

## コンセプト
| | らくらくスマホ | スマートスピーカー | **もしもしAI** |
|---|---|---|---|
| 操作 | タッチと文字入力 | 声だけ | **声と、画面での確認** |
| 手続きの代行 | ✕ | 少しだけ | **◎ AIが代わりに入力** |
| 間違いを防ぐ | 本人まかせ | 画面がない | **必ず画面で確認する** |
| 詐欺対策 | 迷惑電話フィルター程度 | ✕ | **◎ 受ける前・通話中・通話後の3段階** |

### 3つの原則
1. **受話器を上げたら起動**：ウェイクワードもアプリ選びもいりません
2. **画面は入力に使わず、確認するためだけに使う**：AIが入力した内容を大きな文字で表示します
3. **ボタンは3つだけ**：**OK／ちょっと直す／やめる**

## 使い方の例：ネットで買い物
1. 受話器を取って「いつものお米、また頼んで」と話す
2. AIが前回の注文や住所、支払い方法を入れて、画面に表示する
   ```
   ○○米 5kg　2,980円
   お届け：11月6日（金）
   [ OK ]  [ ちょっと直す ]  [ やめる ]
   ```
3. 直したいときは「やっぱり10kgで」と話すだけ

同じやり方で、病院の予約、役所の手続き、宅配の再配達、タクシー、家族へのメッセージ、オンライン診療にも使えます。

## 🛡️ 特殊詐欺から守る（3段階）

### ① 電話を受ける前：AIが先に出る
- **知らない番号・非通知・国際電話**にはAIが先に出て、相手の名前と用件を聞きます。中身を確かめてから「○○市役所の方から、保険の件です」と本人に取り次ぎます
- 通話の最初に「**この通話は録音されます**」と自動で流します（詐欺グループは録音を嫌います）
- 家族や病院など、登録した番号はそのまま本人につなぎます

### ② 話している最中：AIが横で聞いている
- 話の中に詐欺によく出る言葉が出たら、**本人だけに分かるように**知らせます
  - 例：「キャッシュカード」「暗証番号」「還付金」「ATMへ」「逮捕」「示談金」「携帯の番号が変わった」「口座が犯罪に使われている」
- 画面に赤い大きな文字で「**詐欺の疑いがあります。いったん切りましょう**」と出し、受話器の中でもささやきます
- **警察官や役所を名乗る電話**には「警察がお金やカードを預かることはありません」と、その場で正しい知識を伝えます

### ③ 話したあと：確かめて、家族につなぐ
- **本当の相手に自動で確認**：「息子さんを名乗る電話でした。登録してある息子さんの番号に、今から確認の電話をかけますね」
- **家族に通知**：怪しい電話があったら、家族のスマホに日時・録音・要約つきで届きます
- **合言葉**：AIで声をまねる詐欺に備えて、家族だけの合言葉を使えます
- 本人が同意していれば、警察の相談窓口（#9110）につなぎます

### 電話以外の守り
- SMSやメールの**怪しいリンク**は、開く前にAIが止めます
- 買い物は、**AIが信頼できるお店だけ**で代行します（偽の通販サイトには行きません）
- （オプション）インターホンと連携し、「カードを受け取りに来た」という訪問にも警告を出します

### AI自身のルール
> このAIは **絶対に暗証番号を聞かず、振込もすすめません**。

家族と本人にこう約束しておけば、「AIが言っているから」という手口も防げます。

## 💴 お金の安全
- 1回・1か月の**上限金額**を設定でき、超えたら**家族のスマホに承認依頼**が届きます
- 「さっきのやめて」の一言で**キャンセル**できます
- 何を頼んだかを家族が見守りアプリで確認できます（本人の同意が前提）

## 🔧 ハードウェア構成（案）
特別な部品はほとんど要りません。

| 部品 | 内容 |
|---|---|
| 本体 | 市販のタブレット（10インチ前後、スタンドに固定して置いて使う） |
| 受話器 | USBまたはBluetoothの受話器。**フックスイッチ**（受話器を上げた／置いた）を検知してAIを起動・終了 |
| 通話 | 固定電話回線のアダプター、またはIP電話／携帯回線 |
| ソフト | 音声認識 → AIエージェント → 確認画面 → 音声合成。詐欺検知は、できるだけ**端末の中で処理**する |

## ⚠️ 課題と注意すること
- 通話をリアルタイムで聞くので、**本人の同意**とプライバシーへの配慮が必要です
- 本物の電話（病院や銀行など）を詐欺と間違えすぎないように調整します。疑わしいときは「切らせる」より「**確認させる**」方向に寄せます
- AIの聞き間違いや注文ミスがあっても、**必ず画面で確認してから実行**することで防ぎます
- 認知機能が低下した方の利用では、家族の承認範囲を広げられるようにします

## 💡 広め方のアイデア
- 自治体の多くが、**自動通話録音機の貸し出しや購入補助**をしています。この端末がその対象になれば広めやすくなります（制度の内容は自治体ごとに違います）
- 警察・自治体・携帯会社・通販会社・生協・ネットスーパーとの連携
- 端末の販売と、月額料金（AIの利用・見守り）の組み合わせ
